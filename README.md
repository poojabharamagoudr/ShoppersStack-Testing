## ✅ Test Case Format

Each test case includes:
- **TC ID** – Unique identifier
- **Module** – Application module under test
- **Test Scenario** – What is being validated
- **Step No** – Sequential step number
- **Action / Step Description** – What the tester does
- **Test Data / Input** – Data used during execution
- **Expected Result** – What should happen
- **Actual Result** – What actually happened (filled during execution)
- **Status** – Pass / Fail / Blocked
- **Test Type** – Functional / Integration / System / Smoke
- **Severity** – Critical / High / Medium / Low

---

## 🐛 Defect Log

A defect log template is included in Sheet 3 of the Excel file with fields for:
- Defect ID, TC ID, Module
- Title, Steps to Reproduce
- Expected vs Actual Result
- Severity, Priority, Status
- Reporter, Assigned To, Dates
